# Пульс CRM

Универсальная SaaS-CRM для малого и среднего бизнеса: **посещаемость сайта, источники трафика, уходы с сайта, продажи и клиенты в одном окне**. Мультитенантная — каждая компания-клиент получает своё изолированное пространство, поэтому систему можно продавать как сервис.

**Демо:** после включения GitHub Pages — `https://<owner>.github.io/crm/` (работает без сервера, на сгенерированных данных).

## Что умеет

| Раздел | Что внутри |
|---|---|
| **Сводка** | выручка, заказы, конверсия, средний чек, визиты, посетители, отказы, время на сайте — с изменением к прошлому периоду; график по дням; воронка «визит → вовлечение → заявка → заказ»; кто сейчас на сайте |
| **Источники** | каналы и кампании (UTM, яндекс/гугл реклама по `yclid`/`gclid`, поиск, соцсети, рефералы) с визитами, отказами, заказами, конверсией и **выручкой по источнику** |
| **Поведение** | страницы выхода (где уходят с сайта и доля выходов), популярные страницы и время на них, страницы входа с отказами, устройства/браузеры/ОС, события |
| **Продажи** | все заказы (сайт, API, офлайн), статусы, ручное добавление продаж |
| **Клиенты** | карточки, история заказов, сумма покупок, **история визитов клиента на сайт** |
| **Сделки** | канбан-воронка с перетаскиванием, этапы настраиваются |
| **Задачи** | задачи сотрудникам со сроками |
| **Подключение** | код для сайта, ключи, документация API для клиента |
| **Настройки** | компания, валюта, часовой пояс, сотрудники и роли (владелец / администратор / менеджер / наблюдатель) |

## Как данные попадают в CRM

1. **JS-трекер** (`tracker/t.js`, ~3 КБ) — одна строка на сайте клиента:
   ```html
   <script async src="https://ваша-crm.ru/t.js" data-key="pk_..."></script>
   ```
   Собирает визиты, страницы, реферер, UTM, устройство, время на странице, точку выхода. Отслеживает SPA. Формы с email/телефоном автоматически становятся заявками и контактами. Боты и headless-браузеры отсекаются.
   ```js
   crm('lead', { name, email, phone });             // заявка
   crm('purchase', { id, amount, email, items });   // покупка
   crm('event', 'add_to_cart', { sku }, 4990);      // любое событие
   ```
2. **Серверный API** (надёжнее для заказов) — `Authorization: Bearer <secret_key сайта>`:
   - `POST /api/v1/orders` — заказ (идемпотентно по `external_id`, повторная отправка обновляет статус)
   - `POST /api/v1/contacts` — контакт/заявка
   - `POST /api/v1/events` — событие

   Если передать `visitor_id` из `crm('ids')`, заказ привяжется к визиту и рекламному источнику.
3. **Вручную** — офлайн-продажи, звонки, касса.

## Технологии

- **Сервер:** Node.js 22, TypeScript, Fastify, PostgreSQL 16, JWT, zod
- **Панель:** React 18, Vite, Recharts, светлая и тёмная тема, адаптив под телефон
- **Развёртывание:** Docker Compose (приложение + Postgres), GitHub Actions

```
server/      API, приём статистики, миграции (server/migrations/*.sql)
web/         панель управления (и демо-режим для GitHub Pages)
tracker/     t.js — скрипт для сайтов клиентов
```

## Запуск на сервере (VPS)

```bash
git clone https://github.com/Dirol982/crm && cd crm
cp .env.example .env     # заполните JWT_SECRET (openssl rand -hex 32) и PUBLIC_URL
docker compose up -d --build
```

CRM откроется на порту 3000 — поставьте перед ней nginx/Caddy с HTTPS на ваш домен. Миграции базы применяются автоматически при старте. Зарегистрируйте первую компанию на странице входа; чтобы закрыть публичную регистрацию — `ALLOW_SIGNUP=false`.

## Разработка

Нужны Node.js 22 и PostgreSQL.

```bash
cd server && npm install
npm run seed          # миграции + демо-компания: demo@example.com / demo12345
npm run dev           # API на http://localhost:3000
```

```bash
cd web && npm install
npm run dev           # панель на http://localhost:5173 (проксирует /api на :3000)
```

Переменные окружения сервера: `DATABASE_URL`, `JWT_SECRET`, `PUBLIC_URL`, `PORT`, `ALLOW_SIGNUP`, `CORS_ORIGINS` (если панель на другом домене), `WEB_DIST`.

## Демо на GitHub Pages

Workflow `.github/workflows/pages.yml` при каждом пуше в `main` собирает панель в демо-режиме (`vite build --mode demo`) — данные генерируются прямо в браузере, сервер не нужен. Включите в репозитории: **Settings → Pages → Source: GitHub Actions**.

GitHub Pages умеет только статические файлы, поэтому рабочая CRM для клиентов разворачивается на своём сервере (см. выше).
